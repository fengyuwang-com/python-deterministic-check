# python-deterministic-check

跨平台 Python 确定性运算验证工具。

## 目的

检测 Python 运行环境（CPython / PyPy / 其他解释器、操作系统、CPU 架构）是否在所有基础数学运算上产生 **完全一致** 的结果。

当你怀疑 AI 或远端环境没在用真正的 Python 底层、或者换了个环境就跑出不同数字时，跑一遍这个脚本就能验证。

## 测试内容（9 大类）

| # | 类别 | 说明 |
|---|------|------|
| 1 | 大整数运算 | 大数乘法、大指数（`pow`） |
| 2 | 浮点运算 | IEEE 754 加法/乘法/除法/开方 |
| 3 | 高精度 Decimal | 50 位精度的 1/7、√2、复合运算 |
| 4 | 复数运算 | 加法、乘法、欧拉公式 eⁱ |
| 5 | 矩阵运算 | 2×2 矩阵快速幂（斐波那契矩阵 M⁵⁰） |
| 6 | 斐波那契数列 | 快速加倍法：F(100)、F(10000) |
| 7 | 素数筛法 | 埃拉托色尼筛，<1000 的素数 |
| 8 | 数值积分 | 辛普森法，100000 步：π 和 erf(1) |
| 9 | **SHA-256 校验** | 所有结果的哈希值，一行定乾坤 |

## 使用方法

```bash
python benchmark.py
```

无需任何第三方依赖（只用标准库）。

## 验证方法

输出末尾有一行 **SHA-256 校验和**。两台机器跑出相同的 SHA-256，就意味着所有 9 类运算结果完全一致。

参考校验和（CPython 3.11+ / Windows x64 / IEEE 754）：

```
[全局 SHA-256 校验和]
   ef8d257e3a6bcb7a67bace04ae9e0ccb353ed274ea4afd51af5bbc5ef302de65
```

## 设计原则

- **零依赖**：只使用 Python 标准库
- **确定性**：所有循环步数、精度、算法参数硬编码，无随机数
- **跨平台**：不依赖任何平台特定 API
- **快速**：单次运行约 1-3 秒
- **自校验**：末尾 SHA-256 汇总所有中间结果
